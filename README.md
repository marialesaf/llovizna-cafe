# Llovizna Café — demo de Tiale

Web de un café y brunch ficticio en Chapinero Alto, Bogotá. Proyecto demostrativo de Tiale (diseño y desarrollo web a la medida).

- `index.html`: la página completa (estilos, tipografías y código incluidos).
- `media/`: video de la portada y su imagen de carga.

Publicada con GitHub Pages.
